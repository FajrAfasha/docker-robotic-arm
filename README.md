# docker-robotic-arm
This project trains a KUKA YouBot-iiwa model on reaching a desired object in it's space
This repository provides the source files and documentation for a Dockerized robotic arm project.


## Docker Hub Image
The Docker image is available on Docker Hub:
[**fajr2afasha/robotic-arm-env**](https://hub.docker.com/r/fajr2afasha//robotic-arm-env)
Use the command
docker pull fajr2afasha/robotic-arm-env
